# pack:example

**Owning skill:** `uiux-pack-create`  
**Status:** Authoring contract

## Purpose

Create a realistic showcase that makes an Extension Pack's specialist production behaviour visible.

## Inputs

pack production profile; intended use; representative product problem.

## Outputs

showcase definition; complete copyable generation prompt; expected specialist behaviours.

## Must preserve

pack boundaries; core UX invariants; distinction between showcase requirements and an exact answer key.

## Must not

use a generic prompt that would behave the same without the pack; depend on one proprietary runtime unless intrinsically required.

## Failure routing

If the showcase cannot visibly demonstrate material specialist behaviour, reconsider whether the pack is justified.

## Evaluation hooks

Verify prompt completeness, representative difficulty, specialist-behaviour coverage and absence of hidden golden-answer constraints.
