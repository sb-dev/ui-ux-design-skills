# pack:inspect

**Owning skill:** `uiux-pack-create`  
**Status:** Authoring contract

## Purpose

Inspect the current UI/UX Extension Pack catalogue before creating or revising a pack.

## Inputs

requested specialist behaviour; project contexts; existing catalogue.

## Outputs

reuse/adapt/create recommendation with overlap analysis.

## Must preserve

existing pack identities; distinction between core responsibilities and pack specialisation.

## Must not

create a new pack merely because the product category, visual mood or reference differs.

## Failure routing

If the requested behaviour belongs in core, route it to the relevant core skill/spec instead of creating a pack. If an existing pack covers the grammar, adapt that pack or project brief.

## Evaluation hooks

Test duplicate-pack rejection, core-responsibility rejection and a genuinely distinct reusable grammar.
