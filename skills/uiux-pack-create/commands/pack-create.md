# pack:create

**Owning skill:** `uiux-pack-create`  
**Status:** Authoring contract

## Purpose

Define a coherent reusable UI/UX production profile that materially specialises core behaviour.

## Inputs

validated need; target contexts; relevant evidence; existing pack analysis.

## Outputs

pack identity; activation; production profile; affected core skills; stable core invariants; precedence; boundaries.

## Must preserve

core evidence, accessibility, approval, preservation and bounded-refinement rules.

## Must not

turn low-level dimensions into separate packs without demonstrated reuse; duplicate the core lifecycle; invent execution infrastructure.

## Failure routing

If the profile is too project-specific, keep it in the consuming project. If the behaviour belongs in core, route it to the relevant core specification.

## Evaluation hooks

Check that the pack changes observable production behaviour, remains reusable, and leaves core invariants intact.
