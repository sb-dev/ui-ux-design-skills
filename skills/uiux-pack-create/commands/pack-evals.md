# pack:evals

**Owning skill:** `uiux-pack-create`  
**Status:** Authoring contract

## Purpose

Define behavioural evaluation proving that an Extension Pack activates correctly, materially specialises UX work and preserves core invariants.

## Inputs

pack production profile; showcase; core baseline behaviour.

## Outputs

activation, specialisation, precedence, preservation, boundary and core-vs-pack evaluation cases.

## Must preserve

independent semantic judgement; core accessibility/evidence/approval invariants.

## Must not

treat visual difference alone as proof of pack value; omit irrelevant-pack and conflict cases.

## Failure routing

If core + pack cannot outperform or appropriately differ from core alone on the specialist target, revise or reject the pack.

## Evaluation hooks

At minimum cover requested activation, irrelevant non-activation, explicit-instruction precedence, approved-work preservation and core-vs-pack differential behaviour.
