# Level 1 Destructive Confirmation

**Level:** 1  
**Product:** Cloud file-management application  
**Status:** Scaffold definition

## Prompt

Design a proportionate confirmation interaction for permanently deleting a project containing multiple assets. Cover confirmation, processing, success and failure, preserve user control, and avoid unnecessary friction such as mandatory name typing unless the evidence justifies it.

## Primary benchmark focus

interaction correctness; recovery; accessibility; proportionate safeguard.
