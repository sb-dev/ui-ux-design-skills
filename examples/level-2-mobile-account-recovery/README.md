# Level 2 Mobile Account Recovery

**Level:** 2  
**Product:** Native mobile banking application  
**Status:** Scaffold definition

## Prompt

Design an account-recovery task for users who may leave the app to retrieve verification information and then return. Model the task before screens, generate structurally distinct flow alternatives, select the lowest useful fidelity, and cover expiry, resend, interruption and recovery.

## Primary benchmark focus

task model; structural alternatives; interruption/recovery; fidelity selection.

## Scaffold note

Fixtures and reference outputs are intentionally not invented at repository-scaffold stage. Add them when the example is implemented so the source material reflects a real, testable case rather than a fabricated answer key.
