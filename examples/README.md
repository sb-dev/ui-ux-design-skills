# Progressive Examples

Examples are product demonstrations and benchmark inputs, not decorative screenshots.

Initial scaffold subset:

1. Level 1 — destructive confirmation
2. Level 2 — mobile account recovery
3. Level 3 — AI-assisted support reply
4. Level 4 — operations review workspace
5. Level 5 — interrupted financial decision redesign

The full target catalogue remains defined in the canonical specifications. Each example should eventually contain realistic fixtures, expected properties, deliberate traps and an evaluation contract. Multiple valid UX solutions may pass.
