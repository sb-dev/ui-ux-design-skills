# Security Policy

## Reporting

Please report security or privacy issues privately to the repository maintainers rather than opening a public issue when disclosure could expose users, research participants, credentials or sensitive product data.

## Project security boundary

UI/UX Design Skills must not:

- invent or embed credentials;
- bypass consumer-project access controls;
- write to production systems merely to test UX;
- upload sensitive research artifacts to hosted services by default;
- treat optional execution integrations as trusted automatically.

Local execution is preferred where equivalent.
